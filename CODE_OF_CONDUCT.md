# Code of conduct

AskAlbum contributors are expected to communicate respectfully, assume good
faith, focus on technical evidence, and protect user privacy. Harassment,
discrimination, personal attacks, doxxing, deliberate exposure of private
media or credentials, and disruptive behavior are not acceptable.

Project maintainers may remove comments, close discussions, or restrict
participation when this standard is violated. Report conduct concerns privately
through the security/contact route rather than posting personal information in
an issue.
